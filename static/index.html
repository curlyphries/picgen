How characters work

Upload one clear reference picture of a person, pet, mascot or product. Every time you create a picture with that character selected, the studio hands the model the same reference, so the face, build and clothing stay consistent from scene to scene, no retraining, no drift. Describe only what changes: the place, the pose, the outfit, the style. One character per picture keeps the likeness strongest.

How the library works

Every item is a picture of one character showing an expression, a pose or an activity, plus a label and keywords. For the character it was drawn with it is an identity reference. For every other character it is a guide: the generator sees that character's reference together with the library picture and draws the character in the guide's pose or expression. A character can also render its own versions of library items (Characters tab, about 2 min each); those become its own views and are used first afterwards. Garments (outfits, footwear, headwear, accessories, props) are things a character wears or holds: never the identity reference, but extra references added to a picture from the Wearing picker in Create. Auto wears whatever the prompt names.

Learning

Every graded picture teaches the studio. A thumbs down explains what went wrong, offers a fix of just that flaw, and switches on or strengthens a lesson: a rule applied automatically to future pictures. The automatic check (a vision model) looks at every finished picture too; when it finds the same narrow kind of flaw on three pictures, the matching lesson switches itself on. Lessons earn wins and losses from the grades of the pictures they were applied to, so you can see which ones actually help.

How fixes work out

After every fix the automatic check looks again and records which flagged flaws cleared, and whether something else broke (a cleared flaw that cost the likeness does not count). The fix dialog picks the route with the best record for each kind of flaw: words for most things, a pose picture for head direction and body pose.

What it knows about your characters

Fixes name these features so a pose picture or a strong prompt cannot change who the character is; the identity lesson uses them too. They are read once from each character's reference picture by the vision model. If a reading is wrong, correct it here: your wording is kept until the reference picture changes.
